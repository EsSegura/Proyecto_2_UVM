// ============================================================================
//  plusargs.txt  -  Configuracion de la prueba general aligner_test
// ----------------------------------------------------------------------------
//  Uso:   ./simv -f plusargs.txt        (o el ejecutable que genere su flujo)
//
//  Reglas:
//    - Cada plusarg va con el signo '+' adelante, ejemplo: +W_ILLEGAL=100
//    - Las lineas que empiezan con // son comentarios y se ignoran.
//    - Si un plusarg NO se especifica, el test usa su valor por defecto.
//    - Para activar un escenario, se descomenta su bloque y se comentan los
//      demas (no mezclar dos bloques, porque los pesos se contradicen).
//    - Los pesos van de 0 a 100. Peso 0 = desactiva ese valor; peso 100 = lo
//      fuerza; valores intermedios reparten la probabilidad.
// ============================================================================


// ----------------------------------------------------------------------------
//  REFERENCIA DE PLUSARGS (no descomentar esta lista, es solo documentacion)
// ----------------------------------------------------------------------------
//  NOTA: el test base SIN plusargs ya corre el escenario mas general posible
//  (reconfigs, ilegales, size 3, CLR, IRQEN variado y back-pressure activados
//  por defecto) para maximizar la cobertura en una sola corrida. Los plusargs
//  sirven para estrechar a un escenario puntual del plan de pruebas.
//
//  Cantidad de estimulo
//    +NUM_TRANSFERS=N        cantidad de transferencias RX        (default 300)
//
//  Distribucion del estimulo RX (canal de datos)
//    +W_SIZE1=N +W_SIZE2=N +W_SIZE3=N +W_SIZE4=N  pesos del tamano (1,2,3,4 bytes)
//                            (size 3 solo es legal con offset 2)
//    +W_OFF0=N   +W_OFF1=N   +W_OFF2=N  +W_OFF3=N   pesos del offset (0..3)
//    +W_ILLEGAL=N            peso de transferencias ilegales (0..100)
//
//  Consumidor TX
//    +TX_READY_WEIGHT=N      disponibilidad del consumidor (0=siempre ocupado,
//                            100=siempre listo). Sirve para back-pressure.
//
//  Configuracion del registro CTRL (como se configura el alineador)
//    +W_CTRL_SIZE1=N +W_CTRL_SIZE2=N +W_CTRL_SIZE3=N +W_CTRL_SIZE4=N  pesos SIZE
//    +W_CTRL_OFF0=N   +W_CTRL_OFF1=N   +W_CTRL_OFF2=N  +W_CTRL_OFF3=N  OFFSET
//    +W_CTRL_ILLEGAL=N      peso de escrituras CTRL con combos ilegales
//                           (el DUT responde PSLVERR y no cambia la config)
//    +W_CTRL_CLR=N          peso de mandar el bit CLR (limpia CNT_DROP)
//    +N_RECONFIG=N          reconfiguraciones de CTRL en medio del test
//
//  Interrupciones (registro IRQEN). Bit a bit, 0=apagado, 100=encendido
//    +W_IRQEN_RX_EMPTY=N    bit 0  RX_FIFO_EMPTY
//    +W_IRQEN_RX_FULL=N     bit 1  RX_FIFO_FULL
//    +W_IRQEN_TX_EMPTY=N    bit 2  TX_FIFO_EMPTY
//    +W_IRQEN_TX_FULL=N     bit 3  TX_FIFO_FULL
//    +W_IRQEN_MAX_DROP=N    bit 4  MAX_DROP (dispara al saturar CNT_DROP=255)
//    +W_IRQ_CLR=N           peso de limpieza W1C tras leer IRQ
// ============================================================================
